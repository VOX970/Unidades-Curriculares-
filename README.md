## Projeto Integrador

### ConectaStar

>O ConectaStart trabalha com informações de startups, empreendedores, organizações e oportunidades.
As informações mais críticas são o cadastro, estágio da startup, oportunidades, categorias, status e métricas.
As principais fontes são empreendedores, organizações e o próprio sistema.
Os dados são armazenados principalmente em banco de dados PostgreSQL.
As duas informações escolhidas para o ciclo de vida são o cadastro/estágio da startup e as oportunidades.
O ciclo da startup envolve coleta, registro, armazenamento, organização, uso, compartilhamento, atualização e arquivamento.
Os principais riscos são dados incorretos, duplicidade, inconsistência, acesso indevido e informações desatualizadas.
As melhorias incluem validações, identificadores únicos, backups, padronização e controle de permissões.
O ciclo das oportunidades envolve criação, registro, armazenamento, organização, publicação, descoberta, atualização e arquivamento.
As principais melhorias são moderação, filtros por estágio/categoria e revisão periódica das oportunidades.
